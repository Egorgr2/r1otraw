# Настройка системы управления фоновыми изображениями

## 1. Создание таблицы в базе данных

Выполните SQL-скрипт из файла `migrations/create_background_images_table.sql` в Supabase SQL Editor.

**Если таблица уже существует** и вы получаете ошибку с CHECK constraint, выполните только следующие команды:

```sql
-- Обновляем CHECK constraint для типа
ALTER TABLE background_images DROP CONSTRAINT IF EXISTS background_images_type_check;
ALTER TABLE background_images ADD CONSTRAINT background_images_type_check CHECK (type IN ('global', 'home', 'catalog', 'category', 'reviews', 'contacts', 'product'));
```

## 2. Создание Storage бакета

В Supabase Dashboard:

1. Перейдите в раздел "Storage"
2. Создайте новый бакет с именем `backgrounds`
3. Установите "Public bucket" в `true` (чтобы изображения были доступны публично)
4. Настройте CORS (если нужно):
   - Origin: `*`
   - Methods: `GET`, `POST`, `PUT`, `DELETE`
   - Headers: `*`

## 3. Настройка Storage бакета

В Supabase Dashboard (в браузере):

1. Перейдите в раздел "Storage"
2. Создайте новый бакет с именем `backgrounds`
3. Установите "Public bucket" в `true` (чтобы изображения были доступны публично)
4. Настройте CORS:
   - Origin: `*`
   - Methods: `GET`, `POST`, `PUT`, `DELETE`
   - Headers: `*`
5. В настройках бакета отключите RLS (Row Level Security) для упрощения использования через админ-панель

**Примечание:** Если у вас нет прав на изменение настроек RLS через SQL, настройте их через интерфейс Supabase Dashboard.

## 4. Использование в админ-панели

1. Перейдите в админ-панель
2. Нажмите кнопку "Фоны"
3. Нажмите "+ Фон" для добавления нового фона
4. Заполните форму:
   - **Название фона**: Описательное название (например, "Фон для футболок")
   - **Тип страницы**: Выберите тип страницы (Глобальный, Главная, Каталог, Категория и т.д.)
   - **Категория**: Если выбран тип "Категория", укажите название категории (например, "Футболки")
   - **Изображение**: Загрузите файл изображения с компьютера
   - **Цвет затемнения**: Выберите цвет затемнения (по умолчанию черный)
   - **Прозрачность**: Настройте прозрачность затемнения (0-100%, по умолчанию 50%)
   - **Позиция**: Выберите позицию фонового изображения (по центру, сверху, снизу и т.д.)

## 5. Принцип работы

- **Глобальный фон**: Если установлен глобальный фон, он будет применяться ко всем страницам
- **Главная страница**: Показывает фон типа "home" (если нет глобального)
- **Каталог**: Показывает фон типа "catalog" (если выбрана конкретная категория - покажет фон для этой категории, если нет глобального)
- **Страница товара**: Показывает фон типа "product" (если нет глобального)
- **Отзывы**: Показывает фон типа "reviews" (если нет глобального)
- **Контакты**: Показывает фон типа "contacts" (если нет глобального)

Затемнение автоматически применяется поверх фонового изображения для обеспечения читаемости текста.

## 6. Управление фоном

- **Вкл/Выкл**: Включите или выключите конкретный фон
- **Удалить**: Удалите фон (удалит запись из базы данных, но не файл из Storage)
- **Превью**: При добавлении нового фона показывается превью с наложенным затемнением

## 7. Советы

- Используйте изображения высокого качества для лучшего визуального эффекта
- Настройте прозрачность затемнения для оптимальной читаемости текста
- Для категорий можно создавать разные фоны для визуального разделения
- Рекомендуемый размер изображений: 1920x1080px или больше
