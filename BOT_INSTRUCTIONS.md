# 🤖 Telegram Bot - Локальный запуск

## Как запустить бота на вашем ПК

### 1. Установите зависимости (уже сделано)
```bash
npm install
```

### 2. Запустите бота
```bash
npm run bot
```

### 3. Что будет происходить:
- Бот удалит webhook (если был)
- Начнет polling (проверять новые сообщения каждые несколько секунд)
- Будет отвечать на команды `/start`, `/help` и любые текстовые сообщения
- В консоли увидите логи всех действий

### 4. Остановить бота:
Нажмите `Ctrl+C` в терминале

## Преимущества локального запуска:

✅ **Полный контроль** - видите все логи в реальном времени  
✅ **Нет проблем с Vercel** - не зависит от деплоя  
✅ **Как в Python** - работает так же как python-telegram-bot  
✅ **Мгновенные изменения** - изменили код, перезапустили бота

## Минусы:

❌ **Нужен работающий ПК** - если выключите компьютер, бот перестанет работать  
❌ **Нужен стабильный интернет** - бот должен быть онлайн 24/7

## Команды бота:

- `/start` - Открыть магазин с приветствием
- `/help` - Справка по командам
- Любой текст - Предложение написать /start

## Отладка:

В консоли увидите:
- 📩 Сообщения от пользователей
- ✅ Успешные обработки
- ❌ Ошибки если есть

Для постоянной работы бота 24/7:

2. Или настройте запуск на VPS (виртуальном сервере)
